# Изменения для Switch

Всё, что отличает Switch-версию от Android-порта, лежит здесь и
накладывается на игру при каждой сборке (`build.py`):

| Что | Как работает |
|---|---|
| `game/` | Файлы, которые кладутся в папку игры как есть: свои `.rpy` (переопределения экранов, текстов, изображений), свои картинки и шрифты. |
| `assets.py` | Код, который при сборке делает изменённые файлы **из файлов самой игры** (например, логотип с надписью «Switch версия» вместо «Андроид версия»). Описание API — в начале файла. |
| `icon.png` | Своя иконка для главного экрана Switch (необязательно; иначе берётся иконка из APK). |

## Правила

* **Никаких файлов игры в репозитории** — ни картинок, ни скриптов, ни
  шрифтов из APK, даже изменённых. Только свой код и свои файлы; всё, что
  получается из файлов игры, делает `assets.py` при сборке. CI проверяет
  это для типичных форматов.
* Не правьте файлы игры на месте: переопределяйте. В Ren'Py экран,
  объявленный позже (файл `zz_….rpy`, `init` с большим приоритетом),
  заменяет экран с тем же именем; обычный файл важнее файла из `.rpa`.
* Пусть изменения переживают другую версию APK: если нужного файла или
  экрана нет — предупреждение и пропуск, а не ошибка.
* Изменения только для Switch: в этих файлах можно не проверять
  `renpy.switch` — они попадают только в Switch-сборку.
