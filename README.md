# Чудесные дни — Пунктирная жизнь для Nintendo Switch

Неофициальный порт русской версии **«Чудесных дней»** (Subarashiki Hibi
~Furenzoku Sonzai~) на Nintendo Switch с кастомной прошивкой (Atmosphère).

Порт сделан на основе Android-порта от **VienDesu! Porting Team**,
доработанного из порта **Innocence translations**, и работает на движке
Ren'Py 8.5.3 для Switch ([RenpySwitch](https://github.com/LunkezB/RenpySwitch)).

> В репозитории **нет файлов игры** — только скрипт сборки и изменения для
> Switch. Для сборки нужен APK Android-порта: скачайте его у авторов порта.

## Отличия от Android-версии

* Управление с Joy-Con и Pro Controller (см. ниже); жесты Android-порта на
  сенсорном экране работают как раньше (в портативном режиме).
* Можно установить как обычную игру с иконкой на главном экране (NSP).
* В главном меню «Switch версия» вместо «Андроид версия» — на всех
  вариантах титульного экрана (днём, ночью, «1.5»). Надпись нарисована в
  картинках, поэтому `patch/assets.py` при сборке стирает старую и рисует
  новую шрифтом игры (PT Serif).
* В «Об игре» добавлены строка о Switch-порте и адрес этого репозитория.
  Ссылки на Telegram и VK заменены их адресами обычным текстом: на консоли
  нет браузера, так что открыть их там всё равно нельзя.
* Игра определяет режим консоли (портатив / док-станция) так, как это
  делает движок: Android-порт жёстко задавал «телефонные» варианты экранов.
  Из меню игры поэтому пропали «Помощь» (по клавиатуре и мыши) и «Выход»
  (выход есть в главном меню).

## Что нужно

* Switch с Atmosphère. Для NSP — ещё **sigpatches** (если вы уже ставите
  NSP через DBI или Tinfoil, они у вас, скорее всего, есть).
* ПК с Windows, Linux или macOS, [Python](https://www.python.org/downloads/)
  3.8 или новее и библиотека Pillow 11.2 или новее (с AVIF):
  `pip install --upgrade pillow`.
* APK Android-порта от VienDesu! Porting Team.
* Для NSP: `prod.keys` **своей** консоли (их сдампливает Lockpick_RCM, файл
  появится в `sdmc:/switch/prod.keys`). Ключи нужны только на вашем ПК для
  упаковки и никуда не отправляются.

## Сборка

1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.
2. Положите рядом с `build.py` APK игры, а для NSP — и `prod.keys`.
3. Запустите `build-nsp.bat` (NSP + NRO) или `build-nro.bat` (только NRO).
   Или из командной строки:

   ```
   python build.py          только .nro
   python build.py --nsp    .nro и .nsp
   ```

Первая сборка скачивает движок (около 75 МБ), распаковывает игру и
переводит её картинки из AVIF в WebP (Switch не умеет AVIF) — это займёт
около получаса; повторные сборки быстрее. Свободного места на диске
нужно примерно в три раза больше размера игры.

Результат появится в папке `out`.

**Обязательно ли нужен APK?** Лучше собирать из него: из APK берутся игра,
иконка и версия. Если APK нет, подойдёт уже распакованная папка `game`,
например с SD-карты после прошлой сборки (версии `-sw2` или новее: в более
старых картинки не переведены из AVIF):
`python build.py --game путь\к\switch\subahibi\game --nsp`.

## Установка

### NSP — как обычная игра (рекомендуется)

Установите `out/subahibi.nsp` через DBI, Tinfoil или Goldleaf. Игра
появится на главном экране с иконкой и запускается как обычная игра — со
всей памятью консоли. Папка `game` на карте для NSP не нужна.

NSP запускается и на эмуляторе Eden (оконная версия, `eden.exe`).

### NRO — через Homebrew Menu

Скопируйте папку `out/switch` в корень SD-карты, чтобы получилось:

```
sdmc:/switch/subahibi/subahibi.nro
sdmc:/switch/subahibi/game/...
```

Запускайте из Homebrew Menu, открытого **через любую игру с зажатой R**.
Через «Альбом» не запустится: там слишком мало памяти.

Сохранения в обоих случаях лежат в `sdmc:/switch/subahibi/save/`, так что
NRO и NSP видят одни и те же сохранения. Там же, в `save/logs/`, логи —
пришлите их, если что-то сломалось.

## Управление

| Кнопка | Действие |
|---|---|
| A | дальше / выбрать |
| B | назад / меню игры |
| X, − | скрыть текст |
| Y | история (бэклог) |
| ZR | пропуск вкл/выкл |
| ZL | автопрочтение вкл/выкл |
| L / R | быстрое сохранение / быстрая загрузка |
| + | меню игры |
| Правый стик ↑ / ↓ | откат / следующая реплика |
| Левый стик, крестовина | выбор пунктов меню |
| Сенсор | касание — дальше, жесты — как в Android-порте |

## Для разработчиков

Всё, что отличает Switch-версию, лежит в `patch/` и накладывается на игру
при каждой сборке — подробности в [patch/README.md](patch/README.md):

* `patch/game/` — свои файлы в игру (`.rpy` с переопределениями и т. п.);
* `patch/assets.py` — изменённые файлы игры, которые делаются при сборке
  из вашего APK (так в репозитории нет ни одного файла игры);
* `patch/icon.png` — своя иконка (необязательно).

Название, издатель и номер версии порта — в начале `build.py`. Версия
движка — в `engine.txt` (тег релиза RenpySwitch). Опции сборки:
`python build.py --help`.

Изменения удобно делать в Claude Code по своей копии игры — готовый промпт
в [docs/claude-code-prompt.md](docs/claude-code-prompt.md).
