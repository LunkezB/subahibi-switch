# Промпт для Claude Code: изменения для Switch

Изменения Switch-версии (главное меню, «Об игре») делаются по вашей копии
игры, поэтому их удобно делать в Claude Code на своём ПК.

**Подготовка**

1. Клонируйте репозиторий: `git clone https://github.com/LunkezB/subahibi-switch`
2. Положите APK порта от VienDesu! Porting Team в папку репозитория
   (он в `.gitignore` и в коммит не попадёт).
3. Один раз соберите `.nro`, чтобы скачался движок и распаковалась игра:
   `python build.py` (нужны Python 3.8+ и `pip install pillow`).
4. В папке репозитория запустите `claude` и вставьте промпт ниже.

Ghidra не нужна: вся логика игры — скрипты Ren'Py (`.rpy` / `.rpyc`).
`lib/…/librenpython.so` в APK — это сам движок для Android, на Switch он
не используется.

---

```text
Ты работаешь в репозитории subahibi-switch: неофициальный порт русской
версии визуальной новеллы «Чудесные дни — Пунктирная жизнь»
(Subarashiki Hibi) на Nintendo Switch. Основа — Android-порт на Ren'Py от
VienDesu! Porting Team (на базе порта Innocence translations); APK лежит в
корне репозитория. На Switch игра работает на Ren'Py 8.5.3 (проект
RenpySwitch). Сначала прочитай README.md и patch/README.md.

Как устроена сборка: build.py распаковывает APK в out/switch/subahibi/game
(картинки, звук и видео упакованы в switch00.rpa и т. д., скрипты лежат
отдельно), накладывает patch/ и собирает .nro/.nsp. Все изменения для
Switch живут только в patch/:
  - patch/game/ — файлы, которые кладутся в игру (свои .rpy и т. п.);
  - patch/assets.py — код, который при сборке делает изменённые файлы из
    файлов самой игры (API описан в начале файла).

Жёсткие правила:
  1. Никаких файлов игры в git: ни картинок, ни шрифтов, ни скриптов из
     APK, даже изменённых. Изменённые картинки делает patch/assets.py при
     сборке. Перед коммитом проверь `git status`.
  2. Не правь файлы игры на месте — переопределяй (поздний экран с тем же
     именем заменяет ранний; обычный файл важнее файла в .rpa).
  3. Если нужного файла/экрана нет — предупреждение и пропуск, не ошибка.
  4. build.py и движок не трогай. Если найдёшь проблему движка, которая
     касается любых игр (а не только этой), опиши её мне — она
     исправляется в RenpySwitch, а не здесь.

Чтобы изучить игру, распакуй её отдельно, без архивов, в папку вне
репозитория (например C:\tmp\subahibi-src):
  python engine/<версия>/apk2switch.py <APK> -o C:\tmp\subahibi-src --name subahibi --no-controls
Если там только .rpyc без .rpy — декомпилируй unrpyc
(https://github.com/CensoredUsername/unrpyc, ветка для Ren'Py 8).

Задачи:

1. «Андроид версия» → Switch. В главном меню под логотипом написано
   «Андроид версия». Найди, откуда это берётся: текст в скриптах
   (screens.rpy, gui.rpy, options.rpy, переводы tl/) или надпись внутри
   картинки (логотип, фон меню, заставка presplash/splashscreen —
   посмотри сами картинки). Замени на «Switch версия» так, чтобы
   выглядело родным: тот же шрифт, размер, цвет, обводка, положение.
   - Если это текст — переопредели его в patch/game/zz_subahibi_switch.rpy.
   - Если надпись нарисована в картинке — в patch/assets.py при сборке
     сотри её (закрась фоном из соседней области) и нарисуй новую
     шрифтом из игры (через game.read), либо убери из картинки и выведи
     текстом Ren'Py поверх в .rpy. Выбери, что выглядит лучше.
   Проверь все места, где игрок видит «Android»/«Андроид»: меню,
   заставки, «Об игре», заголовок окна, настройки. Найденное перечисли
   мне. Ссылки на Telegram/VK на Switch не открываются (браузера нет),
   их не трогай, но скажи, если считаешь, что их стоит заменить.

2. «Об игре». Сейчас внизу: «Оригинал: KeroQ / Android-порт на Ren'Py».
   Добавь в том же стиле строку о том, что это порт на Nintendo Switch
   на основе Android-порта, например «Порт на Nintendo Switch на основе
   Android-порта (Innocence translations, VienDesu! Porting Team)».
   Точную формулировку и нужно ли указать автора Switch-порта, спроси
   у меня. Предпочтительно изменить только нужный текст/переменную; если
   экран всё же приходится переопределять целиком, переопредели только
   его.

3. Жесты. RenpySwitch добавляет свои свайпы (вверх — история, вниз —
   скрыть текст), только если игра не задала свои в config.gestures.
   Проверь, как сделаны жесты порта VienDesu (свайп вверх — меню, вправо —
   пропуск, влево — откат, вниз — скрыть текст): если через
   config.gestures — всё в порядке; если своим кодом — свайпы будут
   срабатывать дважды, сообщи мне (это исправляется в движке).

4. Варианты экранов. На Switch в портативном режиме активны варианты
   экранов small/phone/touch/switch/mobile, в док-станции —
   large/tv/switch/mobile. Если у игры есть разные версии экранов (порт
   VienDesu увеличивал текст для телефонов), измени все версии, которые
   используются на Switch.

Проверка на ПК (без консоли):
  - python build.py — собирается без ошибок, изменения наложены.
  - Скачай Ren'Py 8.5.3 SDK (https://www.renpy.org/release/8.5.3) и
    проверь out/switch/subahibi: `renpy.exe out/switch/subahibi lint`.
  - Запусти игру из SDK с переменной окружения
    RENPY_VARIANT="small phone touch switch mobile" (портатив) и
    RENPY_VARIANT="large tv switch mobile" (док). Сделай скриншоты
    главного меню и «Об игре» в обоих вариантах (например, временным
    .rpy с renpy.screenshot, который не коммитится) и посмотри их сам.
    Показывай мне скриншоты «до/после».
  - Временные файлы (скриншоты, .rpyc, кеш) не коммить.

В конце: обнови раздел «Отличия от Android-версии» в README.md, сделай
коммит с понятным описанием на русском и запушь. Если что-то неясно в
задаче (формулировки, оформление) — спрашивай меня, а не угадывай.
```
